# 💧 AqylSu — умное управление поливом

**AqylSu** — учебная система моделирования умного полива. Она показывает, как автоматика следит за влажностью почвы, поливает только сухие грядки и ведёт учёт воды.

Это один HTML-файл: без сборки, без установки, без интернета.

> 🌐 **Демо:** https://ВАШ_ЛОГИН.github.io/aqylsu/
> *(замените `ВАШ_ЛОГИН` на ваше имя на GitHub после включения GitHub Pages — см. ниже)*

---

## ✨ Возможности

- **Участки и грядки** — добавление участков, у каждого своя культура, площадь, расход и порог влажности.
- **Камера 3D** — просмотр участка сверху, выбор грядки (А1–А3, Б1–Б3, В1–В3), вода видна только в выбранной области.
- **Автоматический полив** — система включает полив при сухой почве и останавливается на заданной влажности.
- **Расписание** — полив в удобное время.
- **План полива** — подсказка «Что полить сейчас» с оценкой расхода воды.
- **Резервуар** — запас воды, пополнение, предупреждение, когда вода закончилась.
- **История и графики** — динамика влажности, расход воды по времени и по участкам, журнал событий.
- **Скорость симуляции** — 1, 5 или 15 минут фермы за секунду, на паузе — шаг в одну минуту.
- **Резервная копия** — экспорт и импорт всей фермы в JSON, отчёт в CSV.
- **Доступность** — навигация с клавиатуры, «перейти к содержимому», подписи для экранных дикторов.

## 🚀 Запуск

### Вариант 1. Открыть локально
1. Скачайте репозиторий (**Code → Download ZIP**) и распакуйте.
2. Откройте файл `index.html` двойным щелчком.

Интернет и установка библиотек не нужны.

### Вариант 2. Через GitHub Pages
1. Откройте **Settings → Pages**.
2. В разделе **Source** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
3. Нажмите **Save** и подождите 1–2 минуты.
4. Сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`.

## 🎓 Как показать проект на защите

1. Откройте **«Камера 3D»**, выберите участок и грядку.
2. Нажмите **«Смоделировать сухую почву»**, затем **«Полить грядку»**.
3. Наблюдайте, как система поливает и останавливается на заданной влажности.
4. Покажите запись в **«Истории»** и скачайте CSV.

## 💾 Данные

Всё хранится в `localStorage` вашего браузера, на сервер ничего не отправляется.
Перед очисткой данных браузера скачайте JSON-копию в разделе **«Настройки»**. Её можно перенести на другое устройство.

## ⚠️ Важно

Это **учебная симуляция**. Показания датчиков и расход воды моделируются, реальные насосы и датчики не подключены. Пороговые значения заданы для демонстрации — в хозяйстве их подбирают под почву, культуру и калибровку датчика. Подсказки основаны на заданных порогах, а не на агрономическом прогнозе.

## English summary

**AqylSu** is an educational smart-irrigation simulator that runs entirely in the browser from a single `index.html` — no build step, no dependencies, works offline. It models soil-moisture sensors, automatic watering of individual beds in a 3D camera view, a water reservoir, schedules, history charts, and JSON/CSV export. Data is stored locally in `localStorage`. Sensors and pumps are simulated; no real hardware is connected.

**Run:** download the ZIP and open `index.html`, or enable GitHub Pages (Settings → Pages → `main` / root).
