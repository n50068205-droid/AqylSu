# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.0.0] — 2026-11-04

### Добавлено
- Первая публикация проекта на GitHub.
- Участки и грядки (А1–В3), автополив, расписание, резервуар воды.
- 3D-камера с выбором грядки, ракурсами и масштабом.
- План полива с расчётом времени и литров до целевой влажности.
- История, графики, экспорт JSON и CSV.
- Управление скоростью симуляции: 1, 5 и 15 минут в секунду.
- Работа без интернета, хранение данных в `localStorage`.
- Документация: README со скриншотами, шпаргалка для защиты, руководство для участников.
