# Как предложить улучшение

Для сообщения об ошибке или идеи откройте GitHub Issue и выберите подходящий шаблон.

## Изменения кода

1. Создайте отдельную ветку для одной задачи.
2. Внесите изменение в `index.html` и при необходимости обновите документацию.
3. Откройте приложение через локальный HTTP-сервер.
4. Проверьте затронутые действия по [сценарию демонстрации](docs/DEMO.md).
5. Создайте pull request: опишите проблему, результат и выполненные проверки.

Сохраняйте понятный интерфейс и молочно-коричневую палитру. Новые зависимости должны иметь конкретное назначение. Совместимость JSON-копий и формата `localStorage` нужно учитывать при изменении структуры данных.

Если возможность только планируется, обозначайте её как будущую. Расчёты симуляции и реальные измерения должны быть различимы в интерфейсе и документации.
